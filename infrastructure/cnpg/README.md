# infrastructure/cnpg — CloudNativePG operator

Installs the **CloudNativePG** operator (Helm, namespace `cnpg-system`) via its own Flux
Kustomization `cnpg-operator`. It reconciles `postgresql.cnpg.io` `Cluster` CRs into a
running Postgres.

The `user-management-app` app's DB is a `Cluster` CR per namespace
(`apps/user-management-app/k8s/base/db-cluster.yaml`). For each one the operator creates:

| Resource | Notes |
|---|---|
| a Postgres primary pod + PVC | `spec.storage.size` |
| Secret `user-management-app-db-app` | keys `username`, `password`, `dbname`, `host`, `port`, `uri`, `jdbc-uri`, `pgpass` — the API + jobs read `uri` as `DATABASE_URL` |
| Service `user-management-app-db-rw` | read-write (primary). Also `-ro` (replicas) and `-r` (any). |

App-user credentials are **generated by CNPG** — they are not in git and not in OpenBao.
Only the JWT signing secret comes from OpenBao (`ExternalSecret user-management-app-jwt`).

## Verify

```bash
kubectl get pods -n cnpg-system                              # cnpg-controller-manager  1/1
kubectl get cluster -A                                       # user-management-app-db  → Cluster in healthy state
kubectl get cluster user-management-app-db -n user-management-app-dev-ns -o jsonpath='{.status.phase}{"\n"}'
kubectl get secret user-management-app-db-app -n user-management-app-dev-ns
kubectl -n user-management-app-dev-ns exec -it user-management-app-db-1 -- psql -U appuser -d user-management-app -c '\dt'
```

## Grow / HA later

Bump `spec.instances` (adds replicas + failover), add `spec.backup` with an object-store
(Azure Blob) for PITR, add `monitoring: { enablePodMonitor: true }` for Prometheus.
